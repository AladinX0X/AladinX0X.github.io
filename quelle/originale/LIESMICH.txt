ORIGINAL-BILDER (Renderings, Fotos, Plaene)
============================================

Die Original-Dateien liegen hier in einem Ordner pro Projekt:
  quelle/originale/<projekt-slug>/   z. B. quelle/originale/villa-homs/A-1.png
Dieser Ordner ist NICHT im Git (zu gross), nur diese Datei.

So kommt ein neues Bild auf die Website:
1. Datei in den Ordner des Projekts kopieren
   (JPG, PNG, TIFF, WebP; HEIC vorher umwandeln:
    sips -s format jpeg bild.heic --out bild.jpg).
2. In src/data/bilder.json eintragen, z. B.
     "villa-homs-garten": { "art": "foto", "quelle": "originale/villa-homs/garten.jpg" }
   Der Name links (Bild-ID) nur mit Kleinbuchstaben, Ziffern, Bindestrichen.
3. Die Bild-ID in src/data/projekte.json bei "galerie" (oder "titelbild")
   einsetzen und alt-Texte in beiden Sprachen (ar.alt / en.alt) ergaenzen.
4. Im Projektordner im Terminal:  npm run bilder
   (AVIF + WebP in 640/800/960/1440/1920/2560 px, nie hochskaliert,
    Platzhalter, alle EXIF/GPS-Daten werden entfernt)
5. Danach: npm run build (oder Vorschau-starten.command doppelklicken).

Hinweise:
- Je groesser das Original, desto besser (ideal ab 2400 px Breite).
- Hero (Startseite): src/data/site.json "heroBild", Vollbild mit "heroVollbild": true.
- Plaene am besten als PNG in hoher Aufloesung.
